# Zeroday MineReady

Mobile-first English/Spanish contractor readiness, training, and gate-verification demonstration for aggregate and mining sites.

## GitHub Pages deployment

- Repository visibility: Public
- Publishing source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**
- Custom domain: `mineready.zerodaycyber.io`
- DNS: `mineready CNAME zeross11.github.io`

The root of `main` contains the complete static application, `CNAME`, `.nojekyll`, PWA manifest, service worker, and health endpoint. No build command is required.

This demo uses fictional data stored in the browser. It is not a production system of record.
