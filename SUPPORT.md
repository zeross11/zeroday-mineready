# Support

## Public demo support

Public issues may be used for reproducible defects, accessibility problems, broken documentation, or demo usability feedback. Include:

- MineReady release shown in the application
- Browser and operating system
- Device or viewport size
- Workspace and language
- Exact reproduction steps
- Expected and actual behavior
- A screenshot only when it contains fictional demo data

Search existing issues before opening a new one. Never attach browser profiles, storage exports, credentials, private logs, or real operational data.

## Security reports

Do not use public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## Out of scope

This public repository does not provide regulatory, legal, certification, curriculum-approval, production integration, identity, access-control, or live operational support. Contact Zeroday Security Solutions through [zerodaycyber.io](https://zerodaycyber.io) for product discussions.
